# Phase 3g first run, kept (fictional company, sample records)

*Sample records for a demo.*

The first full run of `tools/owners.py` (11/10/2026, 25 log rows, 27 output files) caught all 10 planted problems and passed `tests/check_phase3g.py` G1-G7. A research assistant then reviewed the built New owners tab and answered "No" to "is this how owner onboarding works?", with ranked fixes. The ones that held up changed the helper's wording and the rules' wording, not any answer:

- record a short deposit right away (owed per the lease, cash received, the difference open) instead of leaving the opening balance blank;
- "Money active" becomes "Accounting approved," with what it allows spelled out; a missing bank check holds owner payouts only;
- the owner call-back uses a number Palmquay already had or confirmed separately, not only the one in the packet;
- the tenant letter becomes a management-change notice (who receives notices, how to pay, the deposit's new location and depository), due 30 days after the deposit moved;
- a foreign owner's tax form isn't presumed to be W-8ECI.

So this run was set aside, not edited: its log, chain, and outputs are here as they were. `company/owner-rules.json` was changed, the frozen list was re-made and re-locked (the answer key and its lock line are unchanged), and the helper ran again from a fresh log.
